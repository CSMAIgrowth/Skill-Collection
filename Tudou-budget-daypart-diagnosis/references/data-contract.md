# 数据接入与证据约定
## 调用顺序
1. 只在用户要求执行客户分析时读取客户数据。改造、学习或审核本技能不触发真实查询。
2. 使用目标 agent 已接入的 SparkX MCP。先发现工具并读取当次 schema，调用 get_user_authorized_context，核对用户指定客户/店铺与授权 profile 的唯一映射。不可拿整个授权账户集合代替用户的单客户范围。
3. 通过 get_entity_metadata 读实体与当前配置；get_ads_perf 读广告表现；需要实际操作事件才调用 get_operation_log。profileIds 显式传入授权范围，不传自造 tenantId/userId，不假设获取token即可获得额外权限。
4. 已有接口说明的只读scope分别为 amazon_sa:ads_configuration:read、amazon_sa:performance:read、amazon_sa:ads_logs:read；仍以现场schema为准。不在包内携带认证文件、固定账户、数据库连接或内部表结构。
5. 核对请求与响应 effectiveProfileIds，防止越权ID被静默过滤造成漏店；全量分页后核查覆盖。Performance与metadata字段命名不同，不混用；先查字段字典再选择实体和指标，不拼接不存在的小时/历史成员字段。
6. 使用工具当前明确支持的日期限制、分页和过滤参数；有界分批并记录失败范围。仅暂态只读失败重试一次；权限失败不重试绕过。没有目标工具时明确缺哪项能力，不降级直连内部数据库。
## 必需语义
记录店铺时区、起止日期含首尾、币种、归因窗口、指标定义、查询时间、分页与覆盖。日/小时缺失不补0；只有明确零行省略约定且覆盖完整才补0。订单不能替换为销量。比例用原始分子分母合计重算，分母0标不可计算，不输出0%或无穷大。
ACOS=Spend/广告归因Sales；ROAS=Sales/Spend；CPC=Spend/Clicks；CTR=Clicks/Impressions；CVR=广告归因Orders/Clicks。TACOS须可比店铺总销售，不能用广告销售代替。计算内部用小数比例，展示百分号仅乘100一次。MCP已预缩放ACOS/CTR/CVR不再乘100；单位未知的TACOS或Rate先核对不能猜。
单profile优先保留原币种。多profile接口可能自动换算USD，必须按响应确认并标明，不把USD和原币金额重复相加；跨币种无已验证统一口径不汇总。联表先核对粒度和唯一键，防止一对多重复累计。
当前AI配置只能说明现在；历史AI覆盖须有效期间/事件，不可回填全年。订单=点击×CVR、销售=订单×客单价只是数学分解，不自动证明因果。
## 可选来源与降级
卖家精灵和SIF仅作有权限的商品/市场/关键词/流量补充，先发现当前真实工具与schema，记录站点、月份和估算属性；不编造调用名。缺失时只省略市场模块，不伪造竞品实际经营数据，不把客户明细发给第三方。
合同、服务记录、客户认可、历史成员、小时表现和Amazon OOB事件不属于已证实的通用MCP覆盖。优先查询当前真实schema；缺少时仅接受用户授权、具有来源日期/粒度/覆盖说明的导出或材料，并标明不是MCP实时取得。不得以其他客户凭据或内部库兜底。
用户提供材料不等于事实成立，分开原话、系统数据、推断。正文避免私人客户身份；分析期内唯一客户仅内部运行使用。公开包只保留合成样例。
## 权限及交付
只读取、分析、生成本地交付，不创建/编辑/删除托管组，不改预算或否词，不发外部消息。建议不等于执行；涉及业务写入须在独立动作中取得明确授权并回读。输出给当前请求人；另发收件人需另有授权。
