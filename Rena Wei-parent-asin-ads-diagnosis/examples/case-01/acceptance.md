# 静态示例核对与验证边界

- 合成示例：前期广告成本率 = 1,000 / 5,000 = 20%；当期 = 1,200 / 5,500 ≈ 21.8%。

- 2 个示例子体订单合计 70 + 40 = 110，与示例业务订单一致。
- 示例组成本率 = 400 / 2,000 = 20%，低于示意目标 25%。
- HTML 展示七个诊断章节、三档高亮、一级目标与性格核对位置以及全部 13 项操作检查位置。
- 市场、实际性格和操作开关等未提供真实数据；该示例不能按完整客户报告验收。
