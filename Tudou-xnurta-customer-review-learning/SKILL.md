# 客户复盘方法
## 定位与输入
用于学习、审阅和提炼复盘方法，生成复盘卡和行动清单；完整客户报告生产交由相应报告技能。输入须为有授权的脱敏复盘材料、客户目标、指标及窗口、AI成员/动作与使用记录。没有这些材料不能把原范文数字变成客户事实。
## 五层分析
1. AI覆盖：分别看符合资格的活动数量、花费、广告销售占比。不能只凭数量占比判断采用好坏；说明时期、分母及运行/开启差别。
2. 表现：同窗口同口径比较AI与非AI，并同时看花费、销售、订单、ACOS。增长目标与利润目标分别评价；ACOS下降而销售下降不自动算成功。缺对照或成员不可比不能作因果结论。
3. 操作空间：检查目标、预算活跃时段、出价限制、调价/预算/否词/拓词授权和人工覆盖；有日志才说动作发生。不能由“允许”推断“已做”，不能把未取得日志当作从未操作。
4. 账号与工作方式：查看有权限的使用事件、活跃天、处理建议和流程记录。事件次数不等于成功操作、使用效果或节省工时，不输出人员评价或个人隐私。
5. 后续行动：每个关键问题对应对象、建议动作、已确认或待定负责人、时间窗、验收指标和停止条件；区分已完成、正在执行、有授权尚未开始和建议。
## 输出复盘卡
- 目标与范围：客户/站点/窗口/币种/比较基线。
- 五层发现：每层关键事实、意义、反例及影响结论的缺项。
- 结论：目标是否实现、AI能被证实的作用与不能确定的部分。
- 下一步：最多先列3项高优先建议，其余明细附后；不虚构负责人和承诺。
## 方法校验
核算ACOS=总花费/总广告销售额，分母0时未定义；不同币种不混算。使用数据需来源和时间，客户“想法/动机”必须有明确话语依据，不能从数据猜成事实。
原内部客户材料与链接不在公开包内；用 examples/acceptance.md 合成示例演示。真实案例复用须另核实授权并充分去标识。不自动发消息、修改广告或创建派单。

# 发布与复用边界
本包为实验层公开版，非独立 CSM agent 验证通过版。只提供只读分析与建议；不授予账号、广告修改、发信、审批或对外发布权限。示例全部为人工构造的合成数据，不代表真实客户或效果。
使用者自行提供有权限的 CSV/JSON/报表或只读工具。先查工具与字段是否实际存在，不照抄私有数据库或凭据；字段映射见 references/data-contract.md。
作者与包装维护：土豆。公开包不包含原始客户资料、内部链接、私有脚本或账号配置。
