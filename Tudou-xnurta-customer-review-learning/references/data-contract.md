# 五层输入约定
context：匿名客户键、目标、时区、币种、前后日期、来源与完整性。
coverage：eligible_campaigns、ai_campaigns、total_spend、ai_spend、total_ad_sales、ai_ad_sales，注明运行/开启规则。
performance：AI/非AI各自spend/ad_sales/orders/clicks及成员可比性。
action_space：目标及有效期、预算活跃时间、允许动作、实际日志、人工覆盖。
usage：去标识的事件定义、统计窗口、成功状态和覆盖范围；缺失不补零。
plans：对象、建议、已确认负责人或“待定”、时间、指标、真实执行状态。
只提供部分输入可输出对应层，但不得冒称已完成五层事实核验。
