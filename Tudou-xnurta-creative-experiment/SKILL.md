# Xnurta Creative Experiment Skill

## Goal
Convert growth hypotheses into controlled advertising experiments with measurable outcomes.

## Required inputs
- Customer/product/category and target audience.
- Current campaign type: SP/SB/SD/DSP if relevant.
- Baseline metrics: spend, sales, CTR, CVR, ACOS/TACOS, CPC.
- Creative assets / product claims / constraints.
- Experiment duration and budget tolerance.

## Experiment design
1. Hypothesis: one sentence, testable.
2. Variable: creative, audience, keyword/search term, ASIN, bid, landing object.
3. Control group: current setup or matched campaign/ASIN.
4. Success metric: primary + guardrail metric.
5. Duration: enough clicks/orders; do not overread tiny samples.
6. Decision rule: scale / iterate / stop.

## Common experiment types
- Premium value messaging vs discount messaging.
- Hero ASIN vs long-tail ASIN push.
- Category traffic vs competitor ASIN conquesting.
- Brand defense vs growth exploration.
- AI-managed campaign vs manual/control campaign.

## Output
Return an experiment card/table:
- Hypothesis
- Setup
- Owner
- Metric
- Duration
- Decision rule
- Risk
