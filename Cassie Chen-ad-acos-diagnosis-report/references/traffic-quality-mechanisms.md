# 流量质量机制验证

> 公开版说明：案例标识、经营数据及操作轨迹已移除；数值示例为独立构造的虚构演示或字段占位，不代表真实客户结果。诊断时须使用当前授权数据，不能套用示例结论。


用本文件回答“为什么同样的点击不再出单”。不要把 CVR 下降本身当作分析终点。

## 机制总图

```text
AI/人工操作
  ├─ 竞价基价 / 竞价分时 / 位置系数 → 广告排名和位置 → 搜索词池、点击意图、CVR
  ├─ 预算分时 / 日预算 → 在线连续性、断档与重启 → 高峰缺量、低质补量、CVR
  ├─ 否定 / 暂停 / 收割 → 可获得流量的集合 → 出单词消失或低质词占比变化
  └─ 高频调价 / 不止 → 排名振荡、无效花费持续 → 词池漂移、ACOS 恶化
```

分别验证操作事实、机制推断和结果指标。操作事实可以是 A 级证据，位置变化在缺少 placement 数据时通常只是 B/C 级。

## 1. 竞价时段错配与位置变化

### 必做数据

- 全分析期 target 竞价操作：时间、关键词、原值、新值、操作人。
- 基准期和托管期可比窗口的 campaign 小时级订单、点击、花费。
- 两期搜索词级表现；有条件时加入 keyword × placement 数据。

### 验证步骤

1. 用基准期分小时订单和 CVR 定义高转化窗口，不预设时段。
2. 将 AI 操作分为升价、一般降价和“降到底部区间”。底部区间用本案竞价分布定义，例如不高于该关键词历史竞价的低分位或当前竞价范围的最低档；不要跨案例硬编码 `$X`。
3. 按小时汇总三类操作，叠加基准转化曲线。
4. 计算高转化窗口内底部竞价操作占比，并对比其他时段。
5. 检查高转化窗口内分小时花费和订单是否同步下降。
6. 用同一搜索词两期 CVR 排除“词本身变了”的解释。
7. 有 placement 数据时直接比较 Top of Search / Rest of Search / Product Page 的花费、点击和 CVR；没有时明确标注位置变化为间接推断。

### 结论形式

```text
A：高转化窗口内发生了 N 次底部竞价操作，占全部底部操作的 X%。
A：该窗口日均花费由 A 降至 B，订单由 C 降至 D。
B：多个两期共有搜索词的 CVR 同向下降。
C：综合判断，竞价分时导致高转化窗口优质位置流失。
```

不要把“降价必然导致 CVR 下降”当成定律。低竞价也可能降低无效花费；只有当时段、位置/同词表现和结果一致时才下此结论。

## 2. 预算释放错配与 OOB 断档

### 回放预算，而不是只数预算操作

逐条回放 `DailyBudget Increased/Decreased`，按 `previousValue → newValue` 重建每日预算上限的阶梯曲线。把平台每日固定重置与 AI 策略性爬坡分开。

对基准期典型日、托管期行为切换前后分别回答：

- 高转化窗口开始时可用预算是多少？
- 预算何时恢复到正常水平？
- OOB 发生在高转化窗口前、中、后哪个位置？
- 断档后何时恢复，恢复后花费转移到哪些小时？
- 两期总花费相近时，订单是否仍显著下降？

### 必做对照

| 对照 | 目的 |
|---|---|
| 基准期 vs 托管期 OOB 频率 | 判断断档是否增多 |
| OOB 的小时分布 | 判断是否正好断在高转化窗口 |
| 行为切换前后预算轨迹 | 找策略状态变化起点 |
| 预算恢复/异常充足日 | 做反向验证 |
| 高转化窗口花费保留率 | 区分“总预算不足”与“时段分配错误” |

优先使用操作日志中的 `Campaign Out of Budget` 作为 OOB 直接记录。小时 `spend=0` 只能作辅助，因为低流量、竞价过低和平台归因延迟也会造成零花费。

“重启后平台加速消耗、补到低质流量”属于机制解释；没有直接平台日志证明时标为 C 级，不要写成已观测事实。

## 3. 搜索词池变化：判断原因还是下游结果

### 必做分组

- `共有词`：两期都有花费的同一搜索文本。
- `新增词`：只在托管期出现的词。
- `消失词`：只在基准期出现的词。
- `消失的出单词`：消失词中基准期有订单的词。

### 必算指标

```text
新增词花费占比 = 托管期新增词花费 / 托管期总搜索词花费
新增词 CVR = 托管期新增词订单 / 新增词点击
共有词 CVR = 两期共有词订单 / 共有词点击（分期计算）
异常日零转化词花费占比 = 异常日零订单搜索词花费 / 异常日总搜索词花费
```

### 判读规则

- 新增词多不等于根因。broad match 本来就会轮换长尾词。
- 新增词 CVR 明显低于共有词，才支持“低质新词涌入”。
- 共有词 CVR 同步崩塌，更支持位置、时段或商品转化环境问题，而不是词本身变化。
- 消失出单词若多数只有 1-2 次点击，注明小样本和随机性，不能把历史单次出单当作稳定产能。
- 当词池漂移与竞价高频振荡/位置不稳同时出现时，把词池漂移列为下游结果，除非有独立的定向/否定操作解释它。

## 4. 否定、暂停和收割误伤

逐一交叉核对否定词与基准期搜索词，不要只看操作名称。

1. 找出所有 `Negative Keyword Added`、定向暂停和收割操作。
2. 将否定文本与基准期搜索词做匹配，汇总相关词的花费、订单和销售。
3. 核对匹配类型。日志没有匹配类型时，用“搜索词包含否定文本”计算**潜在误伤上限**。
4. 若该上限内基准期订单为 0，可安全排除明显误杀；若存在出单词，只能写“存在误伤风险”，需元数据或更精确匹配确认。
5. 同时检查人工在广告后台添加的否定词，不能只查 AI。

## 5. 高频振荡与止损失效

### 高频振荡

- 按关键词还原每日竞价轨迹，不只展示最后一天。
- 统计每日操作数、同词反向调价次数、最短反向间隔和全天竞价振幅。
- 对比基准期操作强度；两期操作强度变化是重要背景，须从本案完整日志计算。
- 将振荡与位置/词池稳定性联系时标注推断等级。

### 止损失效

- 找出连续零转化或持续低 CVR 的定向。
- 比较首次满足止损条件与实际暂停/明显降价之间的天数。
- 区分“持续调价”与“实际止损”：反复升降不等于止损。
- 建议用连续零转化天数、点击无单阈值和复活条件，不只写“加强优化”。

## 6. 反向验证与替代解释

优先寻找以下自然实验：

- 某天预算异常恢复充足，CVR 是否同步恢复？
- 某天未执行分时调价，表现是否优于相邻执行日？
- 同一关键词在未降价时段是否保持正常 CVR？
- 同一搜索词在两期的表现是否一致？

同时排除：商品售价/评分/库存变化、Listing 修改、人工干预、预算总额大幅变化、CPC 大幅变化、季节性和小样本波动。广告数据无法排除站外或商品因素时，在数据边界中明确保留。

## 7. 报告中的因果表述

推荐：

> 操作事实（A）→ 对时段/位置/词池的影响（B/C）→ 同词或分小时转化结果（A/B）→ ACOS 结果（A）。

避免：

> ACOS 上升 → CVR 下降 → AI 操作很多 → 所以 AI 导致流量变差。

后者缺少操作与异常窗口的对应关系，也没有证明流量质量通过什么机制改变。
