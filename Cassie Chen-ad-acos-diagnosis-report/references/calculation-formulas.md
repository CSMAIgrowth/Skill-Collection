# 计算公式汇总

> 公开版说明：案例标识、经营数据及操作轨迹已移除；数值示例为独立构造的虚构演示或字段占位，不代表真实客户结果。诊断时须使用当前授权数据，不能套用示例结论。


## 核心指标计算

### ACOS（广告销售成本比）

```
ACOS = 总花费 / 总销售额 × 100%

标注：总花费和总销售额均为期间累计值，不是日均。
```

### CVR（转化率）

```
CVR = 总订单 / 总点击 × 100%

标注：总订单和总点击均为期间累计值。
```

### CPC（单次点击成本）

```
CPC = 总花费 / 总点击

标注：总花费和总点击均为期间累计值。
```

### 日均值计算

```
日均花费 = 总花费 / 天数
日均订单 = 总订单 / 天数
日均销售额 = 总销售额 / 天数

标注：必须说明"日均"，不能省略。
```

## 异常时间点判定

### 日级异常判定

```
异常日判定：
    条件1：当日ACOS > 目标ACOS
    条件2：当日CVR < 基准期CVR × 0.8
    条件3：连续满足条件1和条件2 ≥ 3天

异常起点 = 连续异常的第一天
```

### 小时级异常判定

```
对每个小时段 h（如 8-9时）：

经济损失(h) = 时段日均花费(h) - 时段日均销售额(h) × 目标ACOS

异常小时段 = 经济损失最高的连续2-4个时段

复核指标：
    时段订单损失 = 基准期时段日均订单(h) - 托管期时段日均订单(h)
    时段CVR变化 = 托管期时段CVR(h) - 基准期时段CVR(h)

标注：时段日均 = 该时段总计 ÷ 天数
```

## OOB（预算提前耗尽）分析

### OOB 统计

```
OOB判定：某小时 spend = 0 且该小时之前 spend 已接近日预算

OOB天数 = 统计期内发生OOB的天数
OOB频率 = OOB天数 / 总天数 × 100%

按时段统计：
    OOB次数(时段) = 该时段发生OOB的天数
    OOB占比(时段) = OOB次数(时段) / 总天数 × 100%
```

### OOB 损失估算

```
OOB时段订单损失 = 基准期时段日均订单 - 托管期时段日均订单
OOB时段销售额损失 = OOB时段订单损失 × 客单价

总OOB损失 = Σ(OOB时段订单损失 × 客单价)

标注：时段日均订单 = 该时段总订单 / 天数
```

## 定向竞价分析

### 定向恶化贡献度

```
定向订单损失 = 基准期定向订单 - 托管期定向订单
定向ACOS恶化 = 托管期定向ACOS - 基准期定向ACOS

恶化贡献度 = (定向订单损失 / 总订单损失) × 0.5
           + (定向ACOS恶化 / 总ACOS恶化) × 0.5

按恶化贡献度排序，取Top 3-5
```

### 止损评估

```
止损延迟 = 定向CVR < 阈值的天数 到 定向退出/降价的天数

止损慢判定：止损延迟 > 3天

反复升档判定：
    退出后N天内再次加价，且N < 7
```

## 分时预算分析

### 预算爬坡与需求错配

```
AI预算爬坡曲线：
    budget(t) = 初始预算 + t × 每小时增量

需求曲线：
    demand(t) = 基准期时段日均订单(t)

错配指数 = corr(budget(t), demand(t))

错配判定：错配指数 < 0.3
```

### 高峰预算缺口

```
高峰预算缺口 = 基准期高峰时段日均花费 - 托管期高峰时段日均花费
高峰订单缺口 = 基准期高峰时段日均订单 - 托管期高峰时段日均订单

高峰保留率 = 托管期高峰时段日均花费 / 基准期高峰时段日均花费

标注：高峰时段 = 基准期订单 > 日均150%的时段
```

## 数据标注规范

所有数据展示必须明确标注粒度：

| 表述 | 计算方式 | 使用场景 |
|---|---|---|
| "总花费" | 期间累计 | 期间总计 |
| "日均花费" | 总花费 ÷ 天数 | 跨天平均 |
| "时段日均花费" | 该时段总花费 ÷ 天数 | 某时段跨天平均 |
| "单日花费" | 当天实际值 | 特定某天 |
| "小时均花费" | 该小时总花费 ÷ 天数 | 某小时跨天平均 |

**禁止**：不标注粒度直接写"花费"，除非上下文已明确。

## 流量质量机制指标

### 高转化窗口与窗口保留率

```text
平均每小时订单 = 基准期总订单 / (基准期天数 × 24)

候选高峰小时 = 分小时订单 ≥ 平均每小时订单 × 1.5
               且该小时累计点击达到最小样本量

高转化窗口 = 相邻候选高峰小时合并后的连续时段

窗口花费保留率 = 托管期窗口日均花费 / 基准期窗口日均花费
窗口订单保留率 = 托管期窗口日均订单 / 基准期窗口日均订单
窗口 CVR = 窗口总订单 / 窗口总点击（从总量重算）
```

不要用“某小时订单 > 全天日均订单 × 1.5”定义高峰，量纲不一致。样本太小时同时展示订单和点击，不只展示 CVR 百分比。

### 竞价操作时段错配

```text
底部竞价操作占比(h) = 该小时降到底部区间的操作数 / 全部底部区间操作数

高峰底部操作集中度 = 高转化窗口内底部区间操作数 / 全部底部区间操作数

单词反向调价间隔 = 同一关键词一次升/降价到下一次反向操作的时间差
```

底部区间按本案竞价分布或动作空间的最低档定义，不跨案例硬编码固定金额。

### 同一搜索词 CVR 对比

```text
同词基准 CVR(q) = 基准期搜索词 q 的订单 / 基准期搜索词 q 的点击
同词托管 CVR(q) = 托管期搜索词 q 的订单 / 托管期搜索词 q 的点击
同词 CVR 变化(q) = 同词托管 CVR(q) - 同词基准 CVR(q)
```

仅展示两期都有一定点击量的词，并同时列出点击和订单。单词 1-2 次点击的变化只作小样本提示，不作独立根因证据。

### 搜索词池结构

```text
新增词花费占比 = 托管期新增词花费 / 托管期搜索词总花费
新增词 CVR = 托管期新增词订单 / 托管期新增词点击
消失出单词销售 = 基准期有订单且托管期消失的搜索词销售额之和
异常日零转化词花费占比 = 异常日零订单搜索词花费 / 异常日搜索词总花费
```

搜索词花费合计与 campaign 总花费可能存在归因差异，注明各自数据层，不强行要求完全相等。

### 预算可用性与断档

```text
budget_cap(d, t) = 按操作日志 previousValue → newValue 回放的日期 d 在时刻 t 的预算上限

高峰 OOB 次数 = operationType=Campaign Out of Budget 且发生时间在高转化窗口内的事件数

高峰预算缺口 = 基准期高峰时段日均花费 - 托管期高峰时段日均花费
```

OOB 优先取平台操作日志直接事件；`spend=0` 不作唯一判定依据。

### 否定词潜在误伤上限

```text
潜在误伤订单上限(neg) = 基准期所有包含否定文本 neg 的搜索词订单之和
潜在误伤销售上限(neg) = 上述搜索词销售额之和
```

该口径用于排除风险：上限为 0 时可排除明显误杀；上限大于 0 且匹配类型未知时，只能写“存在风险”，不能直接断言实际误杀。
