# 建议输出格式

> 公开版说明：案例标识、经营数据及操作轨迹已移除；数值示例为独立构造的虚构演示或字段占位，不代表真实客户结果。诊断时须使用当前授权数据，不能套用示例结论。


## 三要素

每条建议必须包含：

| 要素 | 说明 | 示例 |
|---|---|---|
| **动作** | 具体做什么 | 关闭竞价分时，或按基准转化曲线反转分时方向 |
| **针对机制** | 修复哪个已证实问题 | 高转化窗口底部竞价操作过多 |
| **触发条件** | 什么情况下执行 | 高峰 OOB > 2次/天，或高转化窗口订单 < 基准60% |
| **验证与回滚** | 用什么指标、多久验证、失败怎么办 | 观察7天，窗口订单未恢复至70%则关闭分时 |

## 建议表格

```html
<table>
<thead><tr><th>动作</th><th>触发条件</th><th>验证与回滚</th></tr></thead>
<tbody>
<tr>
  <td>取消当前阶梯预算，改回固定预算</td>
  <td>高峰时段订单 < 基准期60%</td>
  <td>观察7天，若订单未回升则回滚到之前策略</td>

<tr>

  <td>低效定向花费占比 > 订单占比 10pp</td>

</tr>
</tbody>
</table>
```

## 按问题类型的建议模板

### 预算分时问题

```
动作：关闭预算分时，恢复固定日预算；或设置“高转化窗口开始前预算≥$X”的硬约束
触发：高峰 OOB > N次/天，或高峰预算保留率 < 60%
验证：观察{N}天，高峰 OOB 应≤N次且不在高转化窗口发生；窗口订单未恢复则回滚/降预算保质
```

### 竞价分时与振荡问题

```
动作：关闭竞价分时，或按基准转化曲线调整方向；绩效调价从每小时降至每4-6小时
触发：高转化窗口底部竞价操作占比异常，或同词单日反向调价>N次
验证：观察{N}天，高转化窗口订单/CVR、同词CVR和词池共有率；未改善则改固定竞价
```

### 定向止损问题

```
动作：按定向建立独立止损——{条件}，{动作}
触发：单个定向连续{N}天0订单，或连续{N}点击无单
验证：暂停{N}天后降价试复活；仍无改善则归档，期间不得反复升降代替止损
```

### 共享预算问题

```
动作：共享预算按定向边际订单效率分层
触发：低效定向花费占比 > 订单占比 {N}pp
验证：每天复核花费份额与订单份额差
```

## 禁止表述

| 禁止 | 正确 |
|---|---|
| "优化预算" | "取消阶梯预算，改为固定日预算$X" |
| "调整竞价" | "将{定向}竞价从$X降至$Y" |
| "观察效果" | "观察7天，若订单未回升则回滚" |
| "必要时" | "若高峰订单<基准期60%，则..." |
