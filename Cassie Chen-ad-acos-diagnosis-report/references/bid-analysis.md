# 定向竞价分析方法

> 公开版说明：案例标识、经营数据及操作轨迹已移除；数值示例为独立构造的虚构演示或字段占位，不代表真实客户结果。诊断时须使用当前授权数据，不能套用示例结论。


## 核心原则

**按定向拆分，不要汇总。**

每个定向有自己的竞价轨迹和 CVR 模式，汇总会隐藏"误杀优质词"等关键问题。

## 分析步骤

### Step 1: 排名定向恶化贡献

```
对每个定向：
    订单损失 = 基准期定向订单 - 托管期定向订单
    ACOS恶化 = 托管期定向ACOS - 基准期定向ACOS

    恶化贡献度 = (订单损失 / 总订单损失) × 0.5
               + (ACOS恶化 / 总ACOS恶化) × 0.5

按恶化贡献度排序，取Top 3-5
```

### Step 2: 单个定向深度分析

对Top问题定向，展示：

```
定向: {name} ({matchType}, targetId: {id})

        基准期          托管期          变化
ACOS    {val}%          {val}%          {change}pp
CVR     {val}%          {val}%          {change}pp
订单    {val}           {val}           {change}%
CPC     ${val}          ${val}          {change}%
花费    ${val}          ${val}          {change}%
```

**竞价操作时间线**：

```
日期/时间  操作人  原竞价  新竞价  变化      操作前CVR  操作后CVR
{时间}     {来源}  {旧值}  {新值}  {变化率}  {CVR前}    {CVR后}
```

### Step 3: 问题判定

| 问题类型 | 判定条件 | 示例 |
|---|---|---|
| **止损慢** | 连续N天0订单/低CVR后才退出 | 6天0订单后才降价 |
| **反复升档** | 退出后7天内再次加价 | 退出后3天再次升档 |
| **误杀优质定向** | 高CVR定向被降价 | CVR>20%的定向被降价30% |
| **过度投资劣质定向** | 低CVR定向被加价 | CVR<5%的定向被加价50% |

### Step 4: 与操作对齐

验证操作时间是否与恶化时间吻合：

```
操作时间 ──→ 恶化开始
    ✓ 吻合 → 该操作可能是根因
    ✗ 不吻合 → 排除该操作
```

## 竞价时段与位置验证

除单定向轨迹外，必须增加“操作发生在什么时段”的分析：

1. 按小时汇总升价、一般降价、降到底部区间的操作数。
2. 叠加基准期分小时订单/CVR 曲线，检查底部操作是否集中于高转化窗口。
3. 对比高转化窗口内两期日均花费、订单和 CVR。
4. 用两期共有搜索词的同词 CVR 验证“词没变但转化变差”。
5. 有 placement 数据时直接验证位置；没有时将位置变化标为间接推断。

底部区间按本案竞价分布或 AI 动作空间最低档定义，不跨案例硬编码金额。竞价振荡按全分析期统计，不要只挑操作最多的一天。
