# 年度价值与服务计划
## 工具能力
本包内置只读查询方法，也支持授权导出。实时工具能力以当前schema、账号权限和成功回执为准；文档存在不等于接口已连接。
可以描述已实际核验的数据整理、诊断和报告产出。广告写操作不在本包范围，不承诺全自动执行或无人值守。
## 价值证据
为客户列已验证结果、可审计过程、待验证收益。不要复用未提供证据的“半小时完成”“60%开启率”“行业第一梯队”或其他客户业绩作为本客户结果。
引用客户案例需可追溯来源、可比范围和使用授权；没有就不引用。人效与收益测算须包含基线、复核成本、成功率和假设，不由操作次数直接换算。
## 四阶段计划
1. 补齐数据与约束：对账、权限、库存/利润、目标有效期、历史成员和日志。交付可验证的数据与问题清单。
2. 小范围验证：有明确风险预算、成功/停止条件的受控比较；设计按基线和样本需求确定，不规定通用固定时长或样本数。
3. 标准化：把验证有效的方法形成团队流程和案例，保留不利结果与适用条件。
4. 审慎扩展：在新增对象上验证外推，不以历史单案例承诺规模化收益。
各阶段日期按客户旺季与服务计划确定，负责人角色仅为建议，不冒充实际派单。
## 商务边界
不写未授权价格/套餐，不承诺合同以外的服务。续约讨论依据客观价值、缺口及可验收下一步，不预设AI一定有效。
