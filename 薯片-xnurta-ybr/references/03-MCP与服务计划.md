# YBR 价值部分：MCP 与服务计划（对客内容）

来源：内部 MCP 客户讲解会议纪要（客户已脱敏）+ SparkX AI MCP 官方说明。**MCP 能力会持续更新，写进报告前先核对官方仓库 README 的当前版本和能力清单**（https://github.com/SparkXAI/SparkXAI-MCP），不要沿用本文的版本号。写进 YBR 第六段之前的「系统价值」或作为路线图的能力支撑。**对客口径，脱内部术语。**

## 一、MCP 能为客户做什么（按模式定制）

**MCP = 智能工作台**：像一个通用接口，把 SparkX 数据和执行能力接进客户自己的 AI 工具，用自然语言下指令完成广告查询和操作，不用来回切后台。截至 2026-10 的官方说明：支持数据查询、AI 托管组管理、SP 广告活动创建、广告实体编辑（预算、状态、竞价、否定投放等）。写操作直接在线上生效，执行前必须确认对象和变更。客户端选择以官方 README 的验收列表为准（国内优先推荐 WorkBuddy）。

按客户模式选话术：
- **精铺大卖（多品牌/多SKU/多站点）**：① 高频重复操作（多店铺切换/新品上架/预算调整/否词）压到半小时；② 库存驱动广告（按库存调整投放，已有精铺客户在用）；③ SKU 全生命周期维护（新品冷启动/成长/清仓）；④ 把常用打法沉淀成标准化 Skill，按月迭代。
- **个人卖家（一人管几十个账户）**：核心是分身乏术 → MCP 把重复操作批量化、用说话代替点击、对接 Sorftime/卖家精灵、Skill 沉淀 = 给一个人配一个不累不忘的助手。

## 二、我们能带来、客户自己拿不到的前沿信息

- 上千家跨品类卖家实战经验：品类在不同站点/阶段怎么打、大促怎么排布。
- 行业第一梯队迭代：AI 托管、MCP、AI 技能体系；产品路线图以官方最新发布为准，不承诺具体上线日期。
- 头部打法可借鉴（脱敏）：某大型卖家假期期间广告无人值守、AI 开启率约 60%，广告规模大幅增长仍维持原团队；某品牌卖家用标准化打法把团队运营水平的下限明显拉高。引用前确认案例口径已经过公司对外许可。

## 三、服务计划四阶段（可套用，按客户实际调整）

| 阶段 | 重点 | 目标结果 |
|---|---|---|
| 旺季前准备（当季） | 校准目标 ACOS；补护栏（竞价区间 / 广告位溢价上下限，部分设置需在平台前台修改，以官方 MCP 写能力清单为准）；把已验证的托管从低覆盖扩到主力 SKU；MCP 基础配置 + 首批 Skill | 达标率回升、CPC 止住上行、MCP 跑通 |
| 旺季爆发（Q4） | 主力品牌开旺季 AI 抢量、MCP 库存驱动动态放量；沉淀旺季优质词与结构 | 抓住大旺季，规模与效率同时兑现 |
| 体系沉淀（次年 Q1） | 用 MCP 每月固化标准操作流程，沉淀词库/广告结构/托管策略模板/标签体系 | 打法标准化、可复制，摆脱对个人手感依赖 |
| 人与 AI 协同（次年 Q2 起） | AI 承担执行层，团队聚焦选品与策略；定期做经营复盘 | 稳定可传承的运营体系 |

配套服务内容以客户实际签约的服务计划为准，不在报告里承诺合同以外的服务。
