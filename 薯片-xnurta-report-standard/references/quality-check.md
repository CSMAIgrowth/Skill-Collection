# 报告交付验收

先修复硬错误，再评价分析深度。完整稿逐项自查；篇幅较长或重大决策报告，使用可用的独立审阅能力核对原始数据与成稿，不让生成者自己的结论充当真值。没有独立审阅工具则明确进行逐项自检，不伪称独立复核。

## 1. 数值和时间（使用代码重新聚合）

- 原始行 → ASIN/管理方式 → 店铺 → 全部，花费、广告销售、点击、展示、订单能够勾稽；排除行/缺失范围/总计含隐藏行均说明。
- ACOS = Σ花费 / Σ广告销售；ROAS 反之；CPC = Σ花费 / Σ点击；广告 CVR = Σ广告订单 / Σ点击；广告客单价 = Σ广告销售 / Σ广告订单；TACOS = 同口径广告花费 / 店铺销售。店铺 CVR 明确订单/会话还是商品件数/会话，禁止混用。
- 分母为零则标 N/A 并保留分子；分子为零且分母>0时比率为0。环比基数零不写无穷增长；占比变化用百分点，百分比增长另标相对变化。
- 汇总比率重新算，不能简单平均行比率。表中金额保持必要精度，展示值四舍五入造成的细微差说明；用未舍入的原始值做推导。
- 口径一致且分母非零时核验 ACOS = CPC/(CVR×客单价)；跨期倍数分解闭合误差应接近机器/舍入误差，超过0.5%排查数据。不要用不同归因订单与销售强行闭合。
- 非等长自然月保留明确总量环比，同时给日均花费/销售等标准化变化；没有逐日数据就不能伪造相同天数子区间。
- 区分业绩期、库存/价格快照、报告生成日；后期快照不能当成当月业绩变化的已证实原因。截止日与当前报告日期核对；季节事件核对年份/站点和官方来源。

## 2. 结论和可比性

- AI 分配到实际生效时段，管理组与广告活动映射无重复计费；字段代理有局限则说明。
- 最强可比案例及反例均可回到原始行；同 ASIN 不代表相同流量。样本大小、覆盖率、关键词/广告位偏差和成熟度可见。
- AI/人工总体差异、同款差异、前后变化均未被写成随机实验。不得用“证明”“消除选择偏差”“AI 一定不影响 CVR”等过强结论。
- 销售增长兼顾流量、CVR、客单价与业务限制；残差销售未被称为广告因果增量；节省金额有反事实公式且标为情景。
- 日志/活跃天数/市场资料缺失时明确未知；没有从经验编造来源或数量。所有证据引用确实存在、可对应表图，市场来源标日期与样本。

## 3. 内容、图和执行

- 老板页有一句主结论、核心 KPI、三条重点和需要做的决策；不是把正文缩成标题列表。
- 店铺差异、AI 采纳与效率、市场/季节、分店诊断、负责人行动表有实质内容；不适用或缺数的模块交代原因及下一步。
- 图依据真实可用序列，缺月份不插值、没有历史就不画趋势；图已渲染、嵌入交付物，中文和标签可读，图与表金额一致。图不是装饰，能支持一条具体决策。
- 每条主要建议定位对象、证据和适用前提，有负责人、截止日期或启动时限、衡量指标，重大投放/系统变更还有停止/回滚条件。未约定的负责人/日期标建议或待确认，不能写成已承诺。库存/利润/预算缺口下没有无条件扩量；数字阈值是业务输入或明确的待验证建议。
- 7/14 天检查兼顾归因回流；未成熟数据只用领先指标，不把短期波动直接当最终盈亏证据。
- 文档回读或本地渲染检查通过；不把标题齐全等同于质量达标。真实客户数据未被复用作公共例子，权限边界保持。

## 常见对抗场景

检查当前输入是否触发：AI 总体更好但同款更差；AI 样本很小；无人工对照；期中切换 AI；30/31天；销售为零；利润或库存未知；无日志；无市场源；节日跨年；过期截止日；仅要求简短结论。正确行为是限定结论、补齐可用证据或适度压缩，不是编造、强迫冗长报告或默认暂停所有工作。
