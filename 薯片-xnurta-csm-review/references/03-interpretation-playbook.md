# 03 · 解读 Playbook（数字 → Insight → 动作）

> 报告的价值不在数字本身，在"翻译"。这页是把指标变化映射成结论和动作的决策树 + 话术。

## A. 五指标环比怎么读
对每组（AI/Non-AI/推动增长/保持稳定）看花费/订单/销售额/转化率/ACOS 五个环比方向：
- **花费↓ + 销售额降幅<花费降幅 + ACOS↓** → 健康收缩（钱花得更精），表述"表现正常/切实下降"。
- **花费↑ + 销售额增幅<花费增幅 + 转化率↓ + ACOS↑** → 增长低效，钱没换来等比产出，要查。
- **花费↑ + 销售额切实增长 + ACOS 微降/持平** → 良性扩张；但若花费涨幅有限，提示"增长是否达瓶颈，考虑补预算或调目标"。
- **转化率↑ 但花费/订单↓** → AI 在剔除低效流量，质量提升、规模收缩——典型 AI 价值信号，对客可强调。

## B. AI 托管检查决策树
### 推动增长组
- 症状：预算活跃时间不足 / 环比花费下降。
- 若"没加预算且在收预算" → 目标错配，建议改【保持订单稳定】。
- 若"人工可接受表现且有条件" → 补预算放量。
- 报告写法：给问题活动条数 + 占该组 Spend%（如"9 条占 40%，急待优化"）。

### 保持稳定组
- 症状：花费水平下降较多。
- 先排除广告因素：是不是 CPC 下降导致？
  - CPC 降多 → 除人工干预外，**排查 AI 目标 ACOS 是否过严**（目标太紧→AI 压 bid→CPC 降→花不出去）。
- 若"ACOS 低但花费不足（预算活跃 100%）"且降幅超预期 → 改【推动增长】先提花费能力。

### 其他（兜底排查）
- 筛选：近 14 天花费 > $20 且销售额环比降 > 30%。
- **四类归因决策树**：
  1. **主观策略**：人工收预算 / 降 CPC / 否了流量 → 查操作记录。
  2. **AI 目标严格**：目标 ACOS 紧 → CPC 被压下来 → 花费能力下滑。
  3. **外部因素**：产品断货 / listing 异常 → 自然权重掉 → 广告带不动。
  4. **其他指标**：CTR↓（广告位偏转 or 展示位竞争变化）；CVR↓（详情页异常/价格/评分）。

## C. "AI 没效果/开了又关" 客诉核查 SOP（高频，且常是误判）
1. **不信轶事**：客户常基于个别烂词/某簇活动下结论，不是看聚合。
2. **拉开关时间线**：`get_ads_perf` 的 aiGroup 维度有 `aiGroup.aiGroupLastStatusOnDate_` / `aiGroup.aiGroupLastStatusOffDate_`；更完整的开关历史查操作日志（entities 选 aiGroup）。
3. **做开启期与关闭期的前后对比**（观察性，不是随机 A/B）：对同批活动，比"AI 开启期"与"AI 关闭期"的**聚合 ACOS / 转化率 / 无效花费**。
4. **内部案例（已脱敏）**：某客户称"6 月开 AI 效果差又关了"。数据显示 AI 开启期 ACOS 约 39%，此前基线约 49%；关 AI 后 ACOS 回升到约 43%。客户的判断和聚合数据不一致。⚠️ 这是观察性前后比较，受季节、促销、预算影响，不能写成"证明 AI 有效"；对客时给出数据，并建议用对照组做一次受控验证。
5. **结论话术**：用聚合数据摆事实，承认个别词或活动表现差；不说"AI 一定好"。

## D. 市场 benchmark 怎么用（CPC 高不高、贵得有没有道理）
SparkX AI MCP 只能看本账号授权店铺，**没有跨客户的类目基准**。可用的对比方式：
- **账户内部对比**：同客户不同店铺、不同托管组、AI 与人工之间的 CPC / CVR 对比（MCP 可取）。
- **外部市场工具**（需 CSM 自己的授权，如卖家精灵关键词出价区间、SIF 竞争结构）：注明工具、日期、站点、样本。
  - 客户 CPC ≈ 市场建议出价 → 出价合理。
  - 客户 CPC 明显高于市场区间上沿 → 可能超投，控 CPC 是优化方向。
  - 客户 CVR 远高于类目常见水平 → 转化强，问题在流量成本，方向是控 CPC，不是换词。
  - 类目以广告为主导、竞争者多 → 高 CPC 是结构性的，单靠压出价压不动，要靠预算分配和词结构。
- 外部工具的搜索量、出价是市场口径，不能当成客户账户的实际数据。

## E. 对客价值话术库（续约/QBR 直接引用）
- **AI 辅助意义**：AI 在广告规则内让高效流量拿更多机会、低效流量减少曝光或被剔除，从而提升全盘效率；规模化提人效、24h 巡航、让偏离目标的广告少花钱。
- **不用 AI 的店 ACOS 往往更高**（店铺分档里常见）→ 用同客户内部对比讨论托管，比讲道理有力；但店铺之间品类和阶段不同，这是相关不是因果，要同时写明。
- **达标率**：综合达标率 X%，头部账号达标率/优良率领先 → 证明 AI 在该客户已跑通，可复制到其他店。

## F. 写报告的纪律
- 环比数字加 **粗体下划线**；每段先数字、后 Insight、再动作。
- 段三是采纳度盘点，给"已搭 N 个 + 下一步配几个"，别空夸。
- 总结段三块：AI 表现（四组+benchmark 收口）/ 系统使用 / 下一步 bullet。
- 对 AI 不利的数据**不删**（报告标准要求保留反例），而是给出解释和改进动作：例如"这几组 AI ACOS 高于人工，主因是目标设置过紧和竞价区间未设置，下期先调整这两项"。术语用客户听得懂的说法。
